# 校正スキル: オウンドメディア エッセイ記事

## Overview

参照ライティングスキル: skills/writing/owned-media-essay.md
目的: note 公開前の最終品質確認。表記、文体、構成、エッセイ固有ルールを多角的にチェックする
対象: Standard Ver.（note向けエッセイ）。Tips Ver.（Zenn「やってみた」スタイル）の場合は末尾の追加チェックも適用する

---

## Phase 1: 表記・文体チェック

以下を全件確認する。

- 固有名詞（プロダクト名、社名、役職者氏名）の正確な表記
- regulation-notation.md の禁止表現の有無
- AIらしい定型表現の有無（「〜と言えるでしょう」「〜ではないでしょうか」の多用）
- タイポ、誤変換、表記ゆれ
- 氏名の姓名間半角スペースの有無
- 文末表現「〜て。」の禁止パターンの有無
- 「まず」の用法の正誤（時系列の始まりを示す場合以外で使っていないか）
- 並列の列挙に「・」を使っていないか（「や」「と」「、」で代替されているか）
- 「——」「ーー」で語句をつないでいないか
- 言葉同士を「＝」でつないでいないか
- 比喩的な表現を使っていないか
- japanese-style.md の英語翻訳調が残っていないか（無生物主語、不自然な受動態、倒置、過剰な指示語）
- 同じ接続詞や同じ文末が近い範囲で連続していないか
- 読点が主題の境目で打たれ、打ちすぎていないか

---

## Phase 2: 構成・エッセイ固有チェック

以下を全件確認する。

- タイトルに「：」が含まれていないか
- リード文が2〜3段落で書かれているか
- リード文が「です・ます」調か
- 中見出しが示唆型または問いかけ型か（トピック説明型「〜について」「〜とは何か」「〜の概要」になっていないか）
- 中見出しが3〜6個配置されているか
- 中見出しに「：」が入っていないか
- 「後述する」と書いた内容が後で必ず説明されているか
- 見出しで宣言した概念の数（「3つ」「4つ」等）と本文の列挙数が一致しているか
- 初出の固有名詞や専門用語に補足説明があるか
- 末尾がコミットメントまたは前向きな展望で締められているか
- 構成を実況・予告する宣言文（「これから結論を言います」「ここからは〜を説明します」「まとめると」）がないか
- 箇条書きやルールの直後に、その内容から自明に読み取れる理由や効果を項目ごとに列挙した冗長な説明がないか
- 「〜ね。」（「ですね」「ですよね」を含む）が1記事に2つ以上ないか
- 対句や畳みかけ（「Aではなく、B」「少し前まで〜。今は違います」等）を多用していないか（1記事1回まで）
- 体言止めや言い切りを連ねて文章を決めすぎていないか

```
校正レポート（{件数}件）

  修正案: {具体的なテキスト}
```

---

## Output Rules

- 出力は Markdown で行う（** の使用は禁止）
- 指摘と修正案は1件ごとに必ずセットで出力する。指摘のみ、修正案のみの単独出力を禁止する
- 確認済み、問題なし、OKの項目は一切出力しない。「確認済み（問題なし）」「問題なし」という見出しや箇条書きは作らない
- 褒める表現は使用しない
- 言葉のトンマナは「ですます調」に統一する

---

## Tips Ver.（Zenn）の追加チェック

Standard Ver. の全チェックに加えて、Tips Ver.（Zenn「やってみた」スタイル）の原稿では以下も確認する。

- 冒頭に TL;DR（3〜5行）があるか
- システム全体像またはファイル構造のコードブロックがあるか
- 実装セクションに実際のコード、設定、コマンドの例があるか
- 「工夫した点・詰まった点」セクションがあるか
- セットアップ方法または再現手順があるか
