## バージョンに関する前提

- 3本とも Blender 2.9 から 3.x 時代の内容で、バージョンは明記されていない。
- 現行の Blender 4.x では、カラーマネジメントのビュー変換の既定が Filmic から AgX に変わっている。動画で「Filmic を標準に変える」と説明している箇所は、4.x では「AgX を Standard に変える」と読み替える。
- 以下の操作は同梱マニュアルで現行版にも存在することを確認した。
  - ポーズのコピーと反転貼り付け。Ctrl+C、Ctrl+V、Shift+Ctrl+V
  - NLA の Push Down Action
  - Shift+A のグリースペンシルにある Object Line Art

## 画面構成

Blender の画面はエリアと呼ぶ複数の区画で構成され、区画ごとに役割が決まっている。

| エリア | 役割 |
|---|---|
| 3Dビューポート | 中央の大きな画面。モデルの操作と編集をする |
| アウトライナー | 右上。シーン内のデータの一覧。名前変更、表示と非表示、レンダリング可否を切り替える |
| プロパティ | 右側。選択中オブジェクトの設定、モディファイア、マテリアル、レンダリング設定 |
| タイムライン | 下。アニメーションの再生と開始終了フレームの設定 |

画面上部のタブはワークスペースと呼び、作業に応じて切り替える。Layout がモデリング、Shading がマテリアル、Animation がアニメーションに特化している。

### マウスカーソルの位置で操作が変わる

Blender はマウスカーソルが置かれたエリアに対してショートカットが働く。
視点操作や Shift+A の追加は、カーソルが 3Dビューポート上にないと動かない。
「操作が効かない」ときは、カーソルの位置、現在のモード、ツールバーの選択ツールの3点を順に確認する。

## おすすめの初期設定

編集メニューのプリファレンスから設定する。プリファレンスは既定で自動保存される。

| 項目 | 場所 | 推奨値 | 理由 |
|---|---|---|---|
| 言語 | インターフェイス | Japanese | 初回起動のクイックセットアップでも設定できる |
| アンドゥ回数 | システム | 50から100 | 既定の32では足りないことが多い。増やすとメモリを使う |
| 選択部分を中心に回転 | 視点の操作 | 有効 | 選択物を中心に視点が回り、確認しやすい |
| 深度 | 視点の操作 | 有効 | ズームインが効かなくなる現象を防ぐ |
| 自動の透視投影 | 視点の操作 | 無効 | 視点を切り替えたときに勝手に透視投影へ戻らないようにする |
| テンキーを模倣 | 入力 | テンキーがない場合のみ有効 | 上段の数字キーで視点を切り替えられるが、一部のショートカットとかぶる |
| 3ボタンマウスを再現 | 入力 | ホイールがない場合のみ有効 | Alt+左クリックが中ボタンの代わりになる |

動画ではテンキーとホイール付きマウスの導入を勧めている。

## 保存と復元

- Ctrl+S で保存する。初回のみ Blender ファイルビューが開き、2回目以降は上書きになる。
- 自動保存は既定で2分おきに動く。強制終了したときは、ファイルメニューの復元から自動保存の一覧を選ぶ。
- 保存せずに終了した場合も、ファイルメニューの復元にある「最後のセッション」で戻せる可能性がある。
- Ctrl+Z で操作を戻す。戻せる回数がプリファレンスのアンドゥ回数で決まる。

## 視点の操作

マウスカーソルが 3Dビューポート上にあることを確認してから操作する。

| 操作 | 内容 |
|---|---|
| 中ボタンドラッグ | 視点の回転 |
| Shift+中ボタンドラッグ | 視点の平行移動 |
| ホイール | ズームインとズームアウト。Ctrl+中ボタンの上下ドラッグでも同じ |
| テンキー1 | 正面 |
| テンキー3 | 右側面 |
| テンキー7 | 上面 |
| テンキー5 | 透視投影と平行投影の切り替え。モデリングは平行投影で行う |
| テンキー0 | カメラ視点。もう一度押すと戻る |
| Ctrl+Alt+テンキー0 | 現在の視点にカメラを合わせる |
| テンキーの / | ローカルビュー。選択中のオブジェクトだけを表示する。もう一度押すと戻る |
| Home | 全オブジェクトが収まるように視点を戻す |

3Dビューポート左上の小さな文字で、現在の視点、投影方法、ローカルビューかどうかを確認できる。

## 選択

| 操作 | 内容 |
|---|---|
| 左クリック | 選択。黄色のアウトラインが付く |
| Shift+左クリック | 追加選択。最後に選んだものがアクティブになり、黄色で表示される。他はオレンジ |
| A | 全選択 |
| 何もない場所を左クリック | 選択解除 |
| 左ドラッグ | ボックス選択。ツールバー最上段の既定ツール |
| W | 選択ツールの切り替え。ボックス、サークル、投げ縄を順に切り替える |
| Alt+左クリック | 編集モードで辺ループ選択 |
| Shift+Alt+左クリック | 辺ループを追加選択 |

アクティブオブジェクトは、複数選択の中で基準になる1つを指す。ミラーやモディファイアの対象になるので、どれがアクティブかを意識する。

W を誤って押して選択ツールが変わってしまう事故が多い。普段はボックス選択に戻しておく。

## オブジェクトの変形

| キー | 内容 |
|---|---|
| G | 移動 |
| R | 回転 |
| S | 拡大縮小 |
| 左クリック | 決定 |
| 右クリック | キャンセル |
| G、R、S の直後に X、Y、Z | 軸に固定して変形する |
| 数値入力 | G、R、S の後に数値を打つと、その量だけ変形する。例、G のあと -5 |

移動と回転は、現在見ている視点に対して平行に動く。軸固定を使うと視点に関係なく一定方向に動かせる。

座標軸は X が赤で左右、Y が緑で奥行き、Z が青で上下を表す。

### オペレーターパネル

オブジェクトを追加したり変形したりした直後、3Dビューポート左下に小さなパネルが出る。
ここで移動量、回転角度、スケール、分割数を数値で指定し直せる。
パネルが消えた場合は F9 で再表示できる。

スケール X、Y、Z のように複数の数値欄を同じ値にしたいときは、数値欄を上下に左ドラッグして
3つをまとめて選択してから入力する。左右にドラッグすると値が変わってしまうので上下方向だけに動かす。

## オブジェクトの追加、削除、表示

| 操作 | 内容 |
|---|---|
| Shift+A | 追加メニュー。メッシュ、ライト、カメラ、グリースペンシルなどを追加する |
| X | 削除。編集モードでは頂点、辺、面のどれを消すか選ぶ |
| H | 非表示。G の隣にあるので誤って押しやすい |
| Alt+H | 全て再表示 |
| アウトライナーの目のアイコン | 表示と非表示の切り替え |
| アウトライナーのカメラのアイコン | レンダリングの有効と無効。無効だとレンダリング結果に出ない |

## 3Dカーソルと原点

- 3Dカーソルは赤と白の縞模様の円で、オブジェクト追加の位置と変形の基準になる。
- Shift+右クリックで 3Dカーソルを移動する。Shift+C で中央に戻す。
- 原点はオブジェクト中央のオレンジ色の点で、オブジェクトモードでは動くが編集モードでは動かない。
- ミラーモディファイアは原点を基準に反転するので、左右対称にならないときは原点の位置を疑う。
- 原点を戻す手順は、Shift+C で 3Dカーソルを中央へ戻し、オブジェクトモードでオブジェクトメニューの「原点を設定」から「原点を3Dカーソルへ移動」を選ぶ。

## モード

| モード | 用途 | 切り替え |
|---|---|---|
| オブジェクトモード | オブジェクト全体を動かす | Tab |
| 編集モード | 頂点、辺、面を編集する | Tab |
| ポーズモード | アーマチュアのボーンを動かす | アーマチュア選択中に Ctrl+Tab |

現在のモードは 3Dビューポート左上のプルダウンで確認できる。操作が効かないときはモードを疑う。

## モデリングの基本機能

うさぎのキャラクターを題材に、以下の機能を使う。

### モディファイア

元の形状を壊さずに変形を加える仕組み。プロパティのレンチアイコンから追加する。
右側の × で削除すると元の形状に戻る。

| モディファイア | 内容 | 注意点 |
|---|---|---|
| サブディビジョンサーフェス | 面を分割して滑らかにする | 形状が縮むので、角を残したい辺にはクリースをかける |
| ミラー | 原点を基準に左右対称にする | クリッピングを有効にすると、頂点がミラー側に越えなくなる |
| ラインアート | グリースペンシルに輪郭線を生成する | カメラ視点を基準に生成するので、テンキー0 で確認する |

### 編集モードでよく使う操作

| 操作 | 内容 |
|---|---|
| Ctrl+R | ループカット。辺の上にカーソルを置いて押すと黄色の線が出る。左クリックで確定し、右クリックで中央に配置する |
| E | 押し出し。右クリックでキャンセルすると重なったメッシュが残るので、キャンセル後は必ず Ctrl+Z で戻す |
| Shift+E | 辺にクリースを追加する。係数1でサブディビジョンの影響を受けなくなる。辺が紫色になる |
| 透過表示の切り替え | 3Dビューポート右上の四角が2つ並んだアイコン。ショートカットは Alt+Z。裏側の頂点も選択できる |
| 右クリックメニューのスムーズシェード | 面を分割せずに見た目だけ滑らかにする。オブジェクトモードで使う |

### プロポーショナル編集

選択した頂点の周囲も一緒に動かす機能。3Dビューポート上部の同心円アイコンで切り替える。

- G などで変形中にホイールを回すと影響範囲の円の大きさが変わる。
- 円が見えないときは、小さすぎるか大きすぎるかのどちらかなので、ホイールで調整する。
- オペレーターパネルの「プロポーショナルのサイズ」で数値指定できる。
- 減衰の種類は既定のスムーズでよい。

### UV球の分割数

Shift+A のメッシュから UV球を追加したあと、オペレーターパネルでセグメントとリングを減らす。
動画ではセグメント8、リング4にしてサブディビジョンサーフェスで滑らかにする方針をとる。
一度設定すると次に追加する UV球にも同じ値が引き継がれる。

### 動画のうさぎモデリング手順の要約

1. 顔。UV球をセグメント8、リング4で追加し、サブディビジョンサーフェスを付ける。プロポーショナル編集で上下の頂点を Z 方向に動かし、中央の辺ループを下げる。
2. 耳。別の UV球を追加し、透過表示で下半分の頂点を削除する。上端と下端の辺ループを縮め、ループカットを2本入れて幅を調整し、ミラーで左右対称にする。R で傾け、テンキー3 の側面から後ろへ倒す。
3. 目。UV球をスケール X 0.1、Y 0.05、Z 0.22 にし、顔の正面に配置する。サブディビジョンサーフェスとミラーを付ける。
4. 口。平面を R X 90 で立て、縮小して顔の前面に置く。ループカットして半分を削除し、ミラーでクリッピングを有効にする。中央の頂点にクリースをかけ、E で押し出して厚みを出す。
5. 仕上げ。全パーツを選んで右クリックからスムーズシェードを適用する。アウトライナーで顔、耳、目、口と名前を付ける。

具体的な数値は動画の値に従うより、オペレーターパネルで見ながら調整するほうが再現しやすい。

## セルルックのマテリアル

Shading ワークスペースのシェーダーエディターでノードをつないで作る。

### 3Dビューのシェーディング

3Dビューポート右上の4つの球アイコンで表示を切り替える。

| 表示 | 用途 |
|---|---|
| ワイヤーフレーム | 内部の構造を見る |
| ソリッド | モデリング時の既定 |
| マテリアルプレビュー | マテリアルだけを表示する。ライトは無視する |
| レンダー | ライトを含むレンダリング結果の簡易表示。動作が重くなる |

### ノード構成

既定で付く「プリンシプル BSDF」を削除し、以下の3つを Shift+A から追加してつなぐ。
「マテリアル出力」は全ノードの終点なので残す。

1. シェーダーの「ディフューズ BSDF」。マットな質感の土台になる
2. コンバーターの「シェーダーのRGB化」。影の情報を色に変換する
3. コンバーターの「カラーランプ」。光と影の境界と色を決める

接続は、ディフューズ BSDF から シェーダーのRGB化、その Color から カラーランプ、
カラーランプの Color から マテリアル出力の Surface の順につなぐ。

### カラーランプの設定

- 補間を「リニア」から「一定」に変えると、光と影がはっきり分かれる。
- 一定にした直後は影の面積が大きく真っ黒に見えるので、右側のストップを左へ動かして光の面積を増やす。
- 光側のストップに肌色、影側のストップに影色を設定する。
- 白い背景にしたあと影が消える場合は、光側のストップの位置を 0.95 に設定する。

### カラーマネジメント

レンダープロパティのカラーマネジメントで、ビュー変換を「標準」にする。
既定の変換は色味を暗くするので、セルルックでは元の色がわかりにくい。

### マテリアルの共有と命名

- シェーダーエディター上部の名前欄で、マテリアルに「うさぎ肌」のような名前を付ける。
- 他のオブジェクトに同じマテリアルを割り当てるときは、対象を選択してから新規ボタン横の球アイコンで一覧から選ぶ。
- 真っ黒なマテリアルは、入力の「RGB」ノードを黒にしてマテリアル出力に直結すれば作れる。

## ライト、ワールド、カメラ

### ライト

- 種類はオブジェクトデータプロパティで変える。動画では「サン」にして強さを5にする。
- 向きはオブジェクトプロパティの回転で指定する。動画では X 60、Y 40、Z 0。
- ブログではエリアライトを Shift+A で追加し、G と R で位置と向きを決めている。

### ワールド

ワールドプロパティのカラーで背景色を決める。セルルックでは白にする。

### カメラ

- カメラがないとレンダリングできない。
- テンキー0 でカメラ視点になり、枠の内側だけがレンダリングされる。
- 位置と回転はオブジェクトプロパティで数値指定できる。動画では位置 X 0、Y -12、Z 0.4、回転 X 90、Y 0、Z 0。要確認、字幕の数値は自動生成のため誤読の可能性がある。
- 焦点距離はオブジェクトデータプロパティにある。既定の50を100にするとパースが弱まり、セルルックに向く。
- 現在の視点にカメラを合わせるには Ctrl+Alt+テンキー0 を押す。
- 3Dビューポートで N を押し、ビュータブの「カメラをビューにロック」を有効にすると、視点操作がそのままカメラの移動になる。画角の微調整に使う。

### カメラを被写体の周りで回す

1. テンキー7 の上面図で Shift+A からエンプティの立方体を追加し、被写体の中心に置く。
2. カメラを選び、Shift+クリックでエンプティを追加選択してから Ctrl+P で「オブジェクト。トランスフォーム維持」を選ぶ。エンプティがカメラの親になる。
3. エンプティのオブジェクトプロパティで回転 Z にキーを打つ。1フレーム目と終了フレームで値を変える。
4. 最初のキーを右クリックし、補間モードをリニアにすると等速で回る。

### ラインアートで輪郭線を付ける

1. テンキー0 でカメラ視点にする。
2. 輪郭線を付けたいオブジェクトを選び、Shift+A のグリースペンシルから「オブジェクトラインアート」を選ぶ。
3. アウトライナーに追加されたラインアートを選び、モディファイアプロパティでライン幅を調整する。動画では15。
4. 他のオブジェクトにも付けるときは、ラインアートモディファイアの下矢印から複製し、対象オブジェクトを変える。

## レンダリング

### 静止画

1. アウトライナーのカメラアイコンで、対象オブジェクトのレンダリングが有効か確認する。
2. 上部メニューのレンダーから「画像をレンダリング」を選ぶ。
3. 結果のウィンドウで、画像メニューの「名前を付けて保存」を選ぶ。ファイルフォーマットもここで選べる。

### アニメーション

ブログの手順。レンダーエンジンは既定の EEVEE を使う。

| 設定 | 場所 | 値 |
|---|---|---|
| サンプリングのレンダー | レンダープロパティ | 64 から 256 に上げる。上げるほど時間がかかる |
| スクリーンスペース反射 | レンダープロパティ | 有効。地面の反射を出す |
| モーションブラー | レンダープロパティ | 有効。速い動きに残像が付く |
| フレームレート | 出力プロパティ | 30fps |
| ファイルフォーマット | 出力プロパティ | PNG から AVI JPEG に変更 |
| 出力先 | 出力プロパティ | 任意のフォルダ |

設定後、上部メニューのレンダーから「アニメーションレンダリング」を実行する。ショートカットは Ctrl+F12。
EEVEE は Cycles より速いが、影と質感の正確さでは劣る。

### Cycles と HDRI で写実的に仕上げる

Monster Mash の動画の手順。

1. ワールドプロパティのカラー横の丸いボタンから「環境テクスチャ」を選び、Poly Haven などで入手した HDRI 画像を開く。
2. レンダープロパティでレンダーエンジンを EEVEE から Cycles に変え、デバイスを GPU にする。
3. サンプリングはビューポートとレンダーの両方を64程度にし、レンダーのデノイズを有効にする。
4. 背景の向きを変えるには、シェーダーエディターをワールドに切り替え、環境テクスチャのノードを選んで Ctrl+T でマッピングノードを出し、回転 Z を動かす。
5. Ctrl+T が効かないときは、プリファレンスのアドオンで Node Wrangler を有効にする。
6. 読み込んだモデルの色が背景となじまないときは、テクスチャとシェーダーの間に「RGBカーブ」と「HSV」のノードを挟み、明るさと彩度を調整する。
7. 出力プロパティでファイルフォーマットを FFmpeg にすると動画で書き出せる。

## 2D画像から3Dモデルを作って Blender に読み込む

Web サービスの Monster Mash で画像をなぞって3D化し、アニメーションまで付けて glTF で書き出す。無料で使える。

### Monster Mash での手順

1. ファイルメニューの「Import Template Image」で元画像を読み込む。
2. Draw モードで体と顔の輪郭を一筆書きでなぞる。輪郭の少し内側を通すときれいに膨らむ。
3. Inflate を押すと3D化される。Rotate で左右から確認し、Draw に戻って続きを描く。
4. 脚や耳のように左右対になる部位は、線をダブルクリックして赤にする。Inflate すると反対側も自動生成される。
5. Animate モードで関節にしたい位置を左クリックして赤い点を打つ。脚の付け根と先、首、顔先など。
6. 録画ボタンを押して赤い点をドラッグすると、その動きがアニメーションとして記録される。
7. Save でプロジェクトが ZIP で保存される。続きは Open Project で ZIP を解凍せずに開く。
8. Save の横のメニューから「Export Animation as glTF」で書き出す。設定は既定のままでよい。

### Blender への読み込み

1. 既定の立方体を削除する。
2. ファイルメニューのインポートから glTF 2.0 を選び、書き出したファイルを開く。
3. Space で再生すると、Monster Mash で付けたアニメーションがそのまま動く。

### 注意点

- 一筆書きで描く必要があり、途中で間違えると最初から描き直しになる。
- 細部の質感は粗いので、HDRI と Cycles で環境になじませる前提で使う。
- 草などの環境は別途作る。動画では GScatter アドオンで地面に草を生やしている。

## アニメーションの基礎

### Animation ワークスペースの構成

| エリア | 役割 |
|---|---|
| ドープシート | 下段。キーフレームを打つ |
| タイムライン | 最下段。再生、停止、開始と終了フレーム、自動キー挿入 |
| 左の3Dビュー | カメラ視点の確認 |
| 右の3Dビュー | 作業用 |

### フレームレートと長さ

- 出力プロパティでフレームレートを決める。アニメは24fps、ゲームは30fpsが基本と動画で説明している。
- 長さは「フレーム数 ÷ fps」で決まる。24fpsで24フレームなら1秒になる。
- タイムラインの終了フレームは既定で250なので、作りたい長さに合わせて変える。

### キーフレームの打ち方

1. ドープシートで対象フレームをクリックする。
2. 3Dビューで対象を動かす。
3. 3Dビュー上で I を押し、キーフレーム挿入メニューから「位置」や「位置と回転」を選ぶ。
4. Space で再生し、もう一度 Space で止める。

タイムラインの「自動キー挿入」を有効にすると、動かすだけでキーが入る。作業効率は上がるが、
意図しないキーが入るので、使い終わったら必ずオフに戻す。

### ドープシートの操作

| 操作 | 内容 |
|---|---|
| ホイール | 拡大縮小 |
| 中ボタンドラッグ | 表示位置の移動 |
| キーをドラッグ | 移動 |
| G のあと数値 | 指定フレーム分ずらす。例、G のあと -5 |
| Ctrl+C と Ctrl+V | コピーと貼り付け。複数キーは先頭のキーを基準に貼り付く |
| Shift+D | 複製。続けて数値を打つとその分先に複製される |
| Shift+R | 直前の操作を繰り返す |
| Delete | 削除 |
| 概要行の横矢印 | オブジェクトを展開し、X位置などチャンネル単位でキーを選んで削除できる |
| T | 補間モードの変更。キーを選んで押す |

### 補間モード

- 既定はベジエで、徐々に加速して減速する動きになる。
- ルートボーンを一定速度で進めたいときは、キーを選んで T からリニアにする。ベジエのままだと足が滑って見える。
- 足の接地を安定させたいときも、足のキーをリニアにする。

### アクションとフェイクユーザー

ドープシートのままキーを打つと、アニメーションが1つしか作れない。複数作るには以下の手順を踏む。

1. ドープシートのモード切り替えを「アクション」にする。
2. 「新規」を押してアクションを作り、「歩き」のような名前を付ける。
3. 名前の右にあるフェイクユーザーの盾アイコンを有効にする。無効のままファイルを閉じると、どのオブジェクトにも割り当てられていないアクションが消える。

## ポーズモードでの操作

- アーマチュアを選択し、Ctrl+Tab でポーズモードに入る。
- ボーンを選んで G、R で動かし、I でキーを打つ。
- A で全ボーンを選んで I を押すと、全ボーンに同じフレームでキーが入る。
- Alt+G、Alt+R、Alt+S で位置、回転、スケールを初期状態に戻す。

### ポーズのコピーと反転貼り付け

1. ポーズモードで A を押して全ボーンを選ぶ。
2. 3Dビュー上で Ctrl+C を押す。「ポーズをバッファにコピーしました」と出る。ドープシートのコピーとは別物なので、この手順を飛ばすと反転貼り付けができない。
3. 貼り付けたいフレームに移動する。
4. Shift+Ctrl+V で左右反転したポーズを貼り付ける。Ctrl+V なら反転なしで貼る。

ボーン名に .L と .R の接尾辞が付いていることが反転の前提になる。

### IK と FK

- FK はボーンを1本ずつ回転させる方式で、IK は先端のボーンを動かすと連動して他のボーンが動く方式を指す。
- 本来は使い分けるが、動画は IK だけで歩きと走りを作っている。

## 歩きアニメーションの作り方

### 4つの基本ポーズ

| ポーズ | 内容 | 要点 |
|---|---|---|
| コンタクト | 力が入る直前。かかとが着地し、脚はまっすぐ | 脚を曲げると「もう体重が乗っている」情報を与えてしまう |
| ダウン | 踏み込んだ脚に体重が乗る。腰が最も低い | 膝を曲げることで体重が伝わる |
| パッシング | 踏み込んだ脚の側へ体が傾く中間 | 重心が踏み込んだ脚へ寄る |
| アップ | 踏み込んだ脚をばねにして腰が最も高い | かかとが上がる |

コンタクトとダウンの2つで重みが伝わる。ここが曖昧だと浮いたように見える。

### 24フレームでの配置

| フレーム | ポーズ |
|---|---|
| 0 | コンタクト。左足前 |
| 2 | ダウン |
| 5 | パッシング |
| 7 | アップ。足が重なる6フレーム目の1つ先 |
| 12 | コンタクト。反転 |
| 14 | ダウン。反転 |
| 17 | パッシング。反転 |
| 19 | アップ。反転 |
| 24 | 0フレームと同じ |

### 手順

1. 終了フレームを24にし、アクション「歩き」を作ってフェイクユーザーを有効にする。
2. 0フレームでコンタクトを作る。テンキー3 の側面で、左足を前に出してつま先を上げ、右足を後ろに引いてつま先を接地させる。ルートボーンを少し下げてかかとを地面に付ける。
3. 腕は脚と反対に振る。左足が前なら左手は後ろ。
4. A で全ボーンを選び、I で位置と回転のキーを打つ。
5. ドープシートで0フレームのキーをコピーし、24フレームに貼り付ける。
6. 3Dビューで Ctrl+C でポーズをバッファにコピーし、12フレームで Shift+Ctrl+V で反転貼り付けする。
7. 7フレームでアップを作る。腰を上げ、後ろ足を少し曲げて前へ運ぶ。
8. 2フレームでダウンを作る。腰を下げ、膝を曲げる。
9. アップとダウンのキーをコピーし、14フレームと19フレームへ反転貼り付けする。
10. テンキー1 の正面で、足の X位置のキーをチャンネルごと削除してから内股気味に調整する。
11. 腰の X位置のキーを削除し、パッシングの5フレームで踏み込んだ足の側へ腰を寄せる。17フレームへ反転貼り付けし、0、12、24フレームには中央の腰を複製する。
12. 腕は肩、肘、手先の順にタイミングをずらす。根元が先に動き先端が遅れて追いつく動きをオーバーラップと呼ぶ。
13. Space で再生し、違和感のある箇所を調整する。

### ポーズを決めるコツ

- キャラクターを左右に半分にしたとき、面積が同じになるようにする。偏ると倒れそうに見える。
- 肘を伸ばしきらず、やや曲げる。
- 肩を動かさないと緊張して見えるので、肩は動かす。
- 歩きでは腕の付け根と先端のオーバーラップを大きめに取る。

## 走りアニメーションの作り方

歩きとの違いは、両足が地面から離れる「空中」のポーズが加わる点にある。

### 16フレームでの配置

| フレーム | ポーズ |
|---|---|
| 0 | コンタクト |
| 1 | ダウン |
| 3 | パッシング |
| 4 | アップ |
| 5 | 空中 |
| 8 | コンタクト。反転 |
| 16 | 0フレームと同じ |

パッシング、アップ、空中を作った直後は4、5、6フレームに置き、そのあと Shift で3つを選んで1つ前へずらすと、空中の時間が長くなりメリハリが付く。

### 歩きと違う要点

- 終了フレームを16にしてスピード感を出す。
- 新規アクション「走り」を作り、0フレーム以外のキーを削除し、Alt+G、Alt+R、Alt+S でポーズを初期化してから作る。
- コンタクトで腰は少し下がりかけ、ダウンで最も下がる。
- 後ろ足は地面を蹴っているので膝を強く曲げる。
- 体は前傾させる。速い走りほど前傾を強める。
- 腕は曲げたまま保ち、オーバーラップは小さくする。
- 肩と腰をひねる。地面を受ける側の骨盤が上がるので、反対側の肩を回してバランスを取る。
- 正面から見て足幅を狭くし、頭は中央に残してまっすぐ前を見る。

## ルートボーンで前進させる

1. ルートボーンに0フレームと24フレームで位置のキーを打つ。
2. ドープシートでそのキーを選び、T から補間を「リニア」にする。
3. 足のキーも同様にリニアにし、かかととつま先を基準に G と R で接地を調整する。

ベジエのままだと加減速が付き、足が滑って見える。

## NLA エディターでアクションを組み合わせる

ブログの手順。複数のアクションを重ねて1本のアニメーションにする。

1. ドープシートをアクションモードにし、アクションに「脚」のような名前を付ける。
2. 「Push Down」を押す。アクションが NLA のトラックにストリップとして移る。
3. エディターの種類をノンリニアアニメーションに切り替える。
4. ストリップを選んで N を押すと、サイドバーで開始と終了、切り取り範囲、リピート回数を設定できる。
5. 別のアクションを作りたいときは、アクションタブで新規に作って再び Push Down する。
6. NLA 上で Tab を押すと、ストリップが緑色になり、元のアクションを再編集できる。

### 要点

- 上のトラックにあるアクションほど優先して表示される。画像編集のレイヤーと同じ考え方になる。
- ループ再生はストリップのリピート回数で指定する。
- 操作に癖があるので、何度か触って慣れる必要がある。

## つまずきやすい点のまとめ

| 症状 | 原因 | 対処 |
|---|---|---|
| ショートカットが効かない | カーソルが別のエリアにある | 3Dビューポートにカーソルを置く |
| 操作が効かない | モードが違う | 左上のプルダウンでモードを確認する |
| クリックで選べない | 選択ツールが変わっている | W かツールバーでボックス選択に戻す |
| オブジェクトが消えた | H で非表示にした | Alt+H で再表示する |
| 他のオブジェクトが消えた | テンキーの / でローカルビューになった | もう一度 / を押す |
| オブジェクトが見当たらない | 視点が迷子 | Home を押す |
| 追加したオブジェクトが中央にない | 3Dカーソルがずれている | Shift+C で戻す |
| ミラーが左右対称にならない | 原点がずれている | 原点を3Dカーソルへ移動する |
| プロポーショナル編集の円が見えない | 円が大きすぎるか小さすぎる | ホイールで調整する |
| モデルが真っ黒 | マテリアル出力に何もつながっていない、または影の面積が大きい | ノード接続とカラーランプのストップ位置を確認する |
| レンダリングが暗い | ライトが非表示か不足 | アウトライナーでライトを表示し強さを調整する |
| レンダリングに写らない | アウトライナーのカメラアイコンが無効 | 有効にする |
| 輪郭線が崩れる | ラインアートはカメラ視点基準 | テンキー0 で確認する |
| 反転貼り付けができない | 3Dビューで Ctrl+C していない | ポーズをバッファにコピーしてから Shift+Ctrl+V |
| 保存したはずのアクションが消えた | フェイクユーザーが無効 | 盾アイコンを有効にする |
| 押し出しキャンセル後に面が重なる | E の右クリックキャンセルは頂点が残る | Ctrl+Z で戻す |
| 足が滑って見える | 補間がベジエ | T でリニアにする |
| Ctrl+T でマッピングノードが出ない | Node Wrangler アドオンが無効 | プリファレンスのアドオンで有効にする |
| Monster Mash で描き直しになる | 輪郭は一筆書きが前提 | 途切れないように内側をゆっくりなぞる |
| 脚が走っているように見えない | 関節のキーが同期している | 関節ごとに G で数フレームずらす |

## 覚え方

アイコンにマウスカーソルを合わせて待つと、機能名とショートカットが表示される。
全部を一度に覚えず、この表示を使いながら少しずつ覚える。
